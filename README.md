# Unit Breaker

SI 기본단위 블록을 8방향 경로로 선택하고, 분자와 분모를 지정해 SI 유도단위를 만든 뒤 고유 능력으로 보드를 비우는 실시간 퍼즐 게임입니다. 난이도는 `쉬움 5×5(25개)`, `보통 10×10(100개)`, `어려움 15×15(225개)` 중에서 선택합니다.

## 실행

별도 빌드나 설치가 필요 없습니다. `index.html`을 최신 Chrome, Edge, Firefox 또는 Safari에서 직접 열면 실행됩니다.

로컬 HTTP 환경이 필요하다면 프로젝트 폴더에서 다음 중 하나를 실행한 뒤 표시되는 주소를 여세요.

```bash
python -m http.server 8080
```

배포는 저장소 전체를 GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅의 루트로 지정하면 됩니다. 빌드 명령은 비워 두고 게시 디렉터리는 `/`로 설정합니다.

## 조작

- 마우스 또는 터치: 인접 블록 선택, 재료 역할 변경, 능력 대상 선택
- 게임 상단 `UNIT BREAKER`: 현재 게임을 종료하고 타이틀 화면으로 이동
- 방향키: 보드 포커스 이동
- `Enter` / `Space`: 블록 선택
- `Backspace`: 마지막 선택 취소
- `Esc`: 전체 선택 취소
- `P`: 일시정지
- `H`: 힌트
- `R`: 조합 초기화

난이도별 제한 시간과 힌트는 쉬움 10분·7회, 보통 8분·5회, 어려움 6분·3회입니다. 보드 크기와 초기 블록 수뿐 아니라 중력, 인접 경로, 키보드 이동, 능력 범위도 선택한 크기를 기준으로 계산됩니다. 제작 가능한 유도단위가 없어 셔플이 필요한 상황에서는 힌트 횟수를 차감하지 않습니다.

메인 메뉴의 `무제한 모드`를 켜면 타이머와 셔플 시간 페널티가 적용되지 않습니다. 현재 반응 폭탄 단계에서 제작한 **서로 다른 특수 단위 종류 수**가 `3, 5, 9, 15, 23, ...`의 현재 기준에 도달하면 선택 지점을 중심으로 3×3 범위의 기본 블록을 제거하는 `반응 폭탄`을 획득합니다. 폭탄 선택 모드에서는 3×3 범위가 보드 안에 완전히 들어오는 칸만 강조되며 가장자리 한 줄은 선택할 수 없습니다. 폭탄을 획득할 때마다 고유 단위 목록은 비워지므로, 이전 단계에서 제작했던 단위도 다음 단계에서 다시 세어집니다. 단, 같은 단계 안에서 같은 단위를 여러 번 제작해도 한 종으로만 계산합니다. 폭탄 버튼을 누른 뒤 보드의 강조된 위치를 선택해 사용합니다.

특수 유도단위를 배치하면 즉시 결과만 바뀌지 않고 충전·범위 예고·이동 애니메이션을 거쳐 능력이 실행됩니다. 뉴턴은 방향 선택 후 1.4초 동안 힘의 방향을 표시하고 블록을 실제 방향으로 밀어냅니다. 운영체제의 모션 감소 설정이 활성화된 경우에는 연출 시간을 자동으로 단축합니다.

능력과 후속 중력으로 이동한 블록이 이전에는 없던 유도단위 경로를 만들면 해당 단위를 자동 제작해 연쇄 반응을 이어갑니다. 자동 제작도 점수, 제작 기록, 반응 폭탄 진행도에 수동 제작과 동일하게 반영됩니다. 역할 입력 없이 결과가 겹치는 `N/Pa`와 `Ω/S`는 각각 50:50 확률로 결정하며, 동일한 차원식 자체가 겹치는 `Hz/Bq`와 `Gy/Sv`는 자동 연쇄 후보에서 제외합니다. 연쇄는 최대 10단계까지 이어집니다.

## 구현 구조

- `index.html`: 메뉴, 게임, 조합기, 팝업의 시맨틱 마크업
- `css/style.css`: 반응형 보드, 실험실 UI, 애니메이션, 접근성 스타일
- `js/data/units.js`: 7개 기본단위와 19개 게임 제작 가능 유도단위 데이터
- `js/unit-system.js`: 7차원 벡터 계산, 차원식 표시, 정확한 레시피 판정
- `js/board.js`: 보드 생성, 경로 탐색, 중력, 셔플
- `js/abilities.js`: 유도단위 능력과 연쇄 반응
- `js/game.js`: 중앙 상태, 타이머, 제작·배치, 승패 흐름
- `js/ui.js`: 보드·조합기 렌더링, 도감, 튜토리얼, 결과 화면
- `js/main.js`: 입력 이벤트, 키보드 조작, 디버그 패널
- `tests/run-tests.js`: 차원식, 보드, 중력, 셔플 핵심 회귀 테스트

## 구현된 유도단위

무차원 단위인 라디안(rad)·스테라디안(sr)과 현재 기본량 조합 규칙으로 표현하기 어려운 섭씨도(°C)를 제외한 19개 유도단위를 지원합니다. 헤르츠(Hz), 뉴턴(N), 파스칼(Pa), 줄(J), 와트(W), 쿨롬(C), 볼트(V), 패럿(F), 옴(Ω), 지멘스(S), 웨버(Wb), 테슬라(T), 헨리(H), 루멘(lm), 럭스(lx), 베크렐(Bq), 그레이(Gy), 시버트(Sv), 카탈(kat)이 포함됩니다. 각 단위의 재료, 차원식, 퍼즐 능력과 실제 사용 예시는 게임 내 도감에서 확인할 수 있습니다. 같은 차원식을 공유하는 Hz/Bq와 Gy/Sv는 제작 시 원하는 단위를 선택합니다.

차원 벡터 순서는 `[kg, m, s, A, K, mol, cd]`로 고정합니다. 곱셈은 지수의 덧셈, 나눗셈은 분모 지수의 뺄셈으로 계산합니다. 루멘은 문서 요구사항에 따라 내부 차원을 `cd`와 동일하게 유지하되 게임 제작 비용으로 `cd` 블록 3개를 사용하고, 이 차이를 UI에서 명시합니다.

## 테스트와 디버그

Node.js가 있으면 다음 명령으로 핵심 테스트를 실행할 수 있습니다.

```bash
node tests/run-tests.js
```

`index.html?debug=true`로 열면 시간, 기본단위·특수단위 생성, 중력, 셔플, 승리·패배를 직접 시험하는 패널이 나타납니다.

게임 화면은 980px 이하에서 상태 표시, 보드, 단위 조합기가 위에서 아래로 배치되는 모바일 세로 레이아웃으로 전환됩니다. 타이틀 화면의 기존 반응형 구성은 유지합니다.

## 알려진 제한 사항과 확장

- 데스크톱 1024px 이상을 우선 지원하며, 더 작은 화면에서는 전체 게임 영역을 가로 스크롤로 유지합니다.
- 특수 능력은 SI 단위 의미에서 영감을 받은 퍼즐 표현이며 물리 시뮬레이션은 아닙니다.
- 향후 모바일 드래그 경로 입력, 일일 시드, 리플레이, 사용자 통계, 추가 SI 유도단위를 데이터 중심으로 확장할 수 있습니다.
